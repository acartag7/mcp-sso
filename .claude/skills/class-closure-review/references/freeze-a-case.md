# Freeze a case

When Codex finds a leftover sibling after this skill said
CLEAN — or a follow-up PR is only the next cell of a class
you just merged — freeze it the same day.

## Steps

1. Name the **behavior** in one sentence.
2. Name the **empty cell** (M1–M7).
3. Rebuild a tiny exact head in `evals/<id>/prompt.md` (the
   few files that make the miss visible). Prefer this repo’s
   real function names.
4. Frame it as a CLEAN local pass.
5. Grade the class, not a wording, in
   `evals/<id>/graders/<id>.md`.
6. Add a row to [evals/CORPUS.md](../evals/CORPUS.md): PR,
   class, eval id. Public PR numbers are fine. Do not paste
   unreleased vulnerability detail from a private assessment.

Do not freeze a **new contract class** (that is STOP).
Do not freeze a finding an existing eval already covers.
Keep `class-closed` so a review that always invents a P1
cannot farm the suite.
