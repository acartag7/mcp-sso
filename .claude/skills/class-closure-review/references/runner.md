# Runner (keep the matrices; starve the ceremony)

The review method is exact-head, filled cells, mutation of the
shipped function. That stays. These rules stop a strong pass
from costing 200k tokens on a small diff.

## Budget

Default **40k–60k tokens**. Stay inside it while every
applicable cell is `n/a` or `clean`. Exceed it only after a
**genuine open class** (empty applicable cell, leftover claim,
or unbacked guarantee). A ceremonial walk of stores, schema,
memory, or the live web is not permission to exceed.

Emit the [output contract](output-contract.md) **once**. Do
not repeat VERDICT / FINDINGS / the matrix after the block.

## Classify, then stop

After naming the behavior, mark each of M1–M7 `n/a` in one
line when that axis cannot be a sibling of **this** behavior.
Stores and schema are `n/a` the moment the change does not
admit, persist, or revalidate a row. Do not open those files
to prove the obvious.

`n/a` = not a sibling of this behavior (one-line reason).
Empty = it **is** a sibling, exists in this tree, and you
skipped it. "Exists in the checkout" is not enough to occupy
a cell.

## Commands

Mutations stay under `/tmp` (or another throwaway tree). Do
not edit the reviewed checkout.

After **one** full-suite run that fails for an environmental
shape (`EPERM` on bind, missing sandbox net, no display),
classify that shape and **stop rerunning** the suite. Do not
prove the same `EPERM` three times. Use a narrower command
that still mutates the shipped function, or record the
environment as the reason a full-suite mutation could not
run and fall back to a targeted test.

Default command output: **summaries first**. Capture
`fail` / `pass` counts and the unexpected failure names.
Paste a full log only for a failure that is not the already-
classified environmental shape.

## No extra corpora

Do not search personal memory, a live ChatGPT / vendor
document, or the public web unless the **diff** leaves a
factual question unresolved (a cited RFC clause, a published
client document the change claims to accept, a version pin).
Class closure is in this tree: the SHA, the blast-radius
siblings, the leftover sentences.

The excerpt bakeoff in [evals/RESULTS.md](../evals/RESULTS.md)
is leftover-cell thrash, not a real-review ranking. Do not
pick a model from it. Hosted Codex is still the merge gate.
